# 🚆 IRCTC Next Generation e-Ticketing — Frontend Replica

A multi-page, responsive frontend clone of the **Indian Railway Catering and Tourism Corporation (IRCTC)** web portal, built using **HTML5, CSS3, and Vanilla JavaScript**. This project recreates the core user interface, navigation flows, and interactive booking widgets of India's primary railway reservation platform.

---

## ✨ Features

- **Train Search & Booking Widget:** Interactive source-to-destination search form with station swap functionality, journey date picker, travel class selection (1A, 2A, 3A, SL, CC, etc.), and quota filters (General, Ladies, Tatkal, Lower Berth/Sr. Citizen).
- **Multi-Page Navigation:** Dedicated views for **Train Search Results**, **PNR Status Enquiry**, **Train Schedule**, **Login / Register Modal**, and **Promotional Holidays / Tourism Packages**.
- **Dynamic UI Interactions:** Client-side form validation, interactive seat availability toggles, fare breakdown previews, and responsive navigation menus powered by JavaScript.
- **Responsive Layout:** Styled with modern CSS (Flexbox & Grid) to adapt smoothly across desktop and mobile viewports.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic structure across multiple linked pages
- **CSS3** — Custom styling, Flexbox/Grid layouts, hover states, and responsive breakpoints
- **JavaScript (ES6+)** — DOM manipulation, station-swap logic, interactive modals, and client-side form handling
